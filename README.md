# Mind Companion

Mind Companion is a retrieval-augmented mental health support chatbot.

It combines:
- A crisis classifier for high-risk messages
- Retrieval from a counseling dataset plus curated mental health guidance
- Gemini for empathetic, grounded responses
- A Streamlit chat interface

## Important Disclaimer

This project is educational and is not a replacement for professional mental health care.
If someone is in immediate danger, contact emergency services or a crisis hotline.

## Setup

### 1) Install dependencies

Using Poetry:

```bash
poetry install
```

Or using pip:

```bash
pip install -r requirements.txt
```

### 2) Configure environment variables

Create a .env file at the repository root:

```env
KAGGLE_USERNAME=your_kaggle_username
KAGGLE_KEY=your_kaggle_key
GEMINI_API_KEY=your_gemini_api_key
```

## Typical Workflow

Run the pipeline steps in order:

```bash
poetry run python mind_companion/dataset.py
poetry run python mind_companion/clean.py
poetry run python mind_companion/download_model.py
poetry run python mind_companion/build_index.py
```

Notes:
- The models directory and vector index are generated by the scripts when needed.
- If artifacts are missing, rerun the relevant script above.

## Run the App

```bash
poetry run streamlit run mind_companion/app.py
```

Then open http://localhost:8501.

## Optional Tasks

Generate EDA figures:

```bash
poetry run python mind_companion/eda.py
```

Train classifier yourself (instead of downloading weights):

```bash
poetry run python mind_companion/modeling/train.py
```

Evaluate classifier:

```bash
poetry run python mind_companion/modeling/evaluate.py
```
